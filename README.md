# PriorityFlow

A small React task prioritizer app built with Vite.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages deployment

1. Push this repo to GitHub.
2. In GitHub, open the repository settings.
3. Go to Pages and select the GitHub Actions source.
4. The workflow in `.github/workflows/deploy-pages.yml` will publish the app automatically on pushes to `main`.

The site will be available at:

```text
https://<your-username>.github.io/PriorityFlow/
```
